# Recursos gráficos: procedencia y condiciones de uso

| Recurso | Origen | Condiciones |
|---|---|---|
| Íconos (lupa, carrito, camión, tarjeta, flechas, etc.) | Dibujados a mano como SVG simples dentro de `assets/js/store/templates.js` e `index.html`, creados para esta plantilla | Uso libre dentro de los proyectos que usen esta plantilla |
| Favicon (`assets/img/favicon.svg`) | Creado para esta plantilla | Ídem. Reemplazar por el logo del cliente |
| Tipografía | Fuentes del sistema operativo del visitante (`system-ui`, Segoe UI, Roboto, etc.) | No se descarga ni se distribuye ninguna fuente |
| Recuadro “FOTO DE PRODUCTO” | CSS propio | — |
| Fotos de productos | **No se incluyen.** En la demo no hay fotografías: se muestran recuadros “FOTO DE PRODUCTO” | Las fotos reales las sube cada negocio y debe tener derecho a usarlas |
| Datos de demostración (`data/demo-crm.json`) | Ficticios, escritos para la demo | Sin datos de personas ni empresas reales |

No se usan bibliotecas, frameworks, CDNs ni bancos de imágenes de terceros.

Al adaptar la plantilla, si agregás un logo, fuentes o íconos de terceros,
registrá acá su origen y licencia.
